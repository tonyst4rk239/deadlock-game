# 📜 Manual de Reglas y Mecánicas: DEADLOCK

## 🔄 Estructura de una Ronda (Turno Global)

Cada ronda representa **1 semana** de supervivencia (12 rondas = 3 meses).

```
┌─────────────────────────────────────────────────────────────┐
│ 1. FASE DE AMANECER (Clima y Evento Global del Overlord)    │
│    • El Overlord juega una Condición Global.                │
│    • Afecta a todos los humanos simultáneamente.            │
├─────────────────────────────────────────────────────────────┤
│ 2. FASE DE ACCIÓN HUMANA (En sentido de las agujas del reloj)│
│    • Cada jugador recibe 3 Puntos de Acción (AP).           │
│    • Acciones: Robar Recursos, Construir, Atacar, Traicionar│
├─────────────────────────────────────────────────────────────┤
│ 3. FASE DE NOCHE (Ataque y Asedio del Overlord)             │
│    • El Overlord gasta sus AP en Ataques Directos o Hordas. │
│    • Resolución de dados contra murallas y defensas.        │
├─────────────────────────────────────────────────────────────┤
│ 4. FASE DE MANTENIMIENTO Y HAMBRE                           │
│    • Cada facción viva consume 1 de Comida.                 │
│    • Si no puede pagar: pierde 2 HP por inanición.          │
└─────────────────────────────────────────────────────────────┘
```

---

## 🎲 Sistema de Resolución por Dados

Cuando una acción depende del azar (ej. romper una barricada o emboscar una patrulla), se lanza 1 dado de 6 caras (D6):

| Tirada (D6) | Resultado | Efecto en Barricadas / Combate |
| :---: | :---: | :--- |
| **1 - 2** | **Fallo** | El atacante falla. En caso de ataque del Overlord, sufre daño o retroceso; si es humano, pierde los recursos gastados. |
| **3 - 5** | **Éxito Normal** | El objetivo recibe el daño base indicado en la carta (ej. -2 HP o -1 nivel de barricada). |
| **6** | **Éxito Crítico** | El daño se incrementa en +1 o se aplica un efecto adicional (ej. Brecha Directa / Mordida Gratuita). |
