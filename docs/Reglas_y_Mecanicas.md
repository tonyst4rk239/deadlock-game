# 📜 Manual de Reglas y Mecánicas: DEADLOCK

## 🃏 Taxonomía Oficial de Cartas

El sistema de juego se basa estrictamente en **4 Tipos de Cartas Humanas** más el mazo de **Condiciones del Overlord**:

```
┌─────────────────────────────────────────────────────────────┐
│                    MAZO DE HUMANOS (4 TIPOS)                │
├───────────────────┬───────────────────┬─────────────────────┤
│ 🛡️ 1. DEFENSA    │ ⚔️ 2. ATAQUE      │ 💰 3. ROBO / TRAICIÓN│
│ Murallas, vallas  │ Fuego, trampas,   │ Saqueo a rivales,   │
│ y puestos vigía   │ contrataques      │ sabotajes, desvíos  │
├───────────────────┴───────────────────┴─────────────────────┤
│ 📦 4. RECURSOS                                              │
│ Expediciones, raciones, cultivos, botiquines                │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│               🩸 MAZO DEL OVERLORD (CONDICIONES)            │
├─────────────────────────────────────────────────────────────┤
│ • Condiciones Globales: Invierno, Hambruna, Sequía, Niebla  │
│ • Condiciones de Ataque: Hordas Boomer, Mordidas, Corredores│
│ • Condiciones de Mejora: Frenesí de Sangre, Mutaciones      │
└─────────────────────────────────────────────────────────────┘
```

## 🔄 Estructura de una Ronda (Turno Global)

Cada ronda representa **1 semana** de supervivencia (12 rondas = 3 meses).

1. **Fase de Amanecer (Condiciones del Overlord):**
   - El Overlord juega 1 carta de Condición Global o Desastre.
   - Aplica su efecto a todos los humanos vivos.
2. **Fase de Acción Humana:**
   - Cada jugador dispone de **3 AP** para jugar cartas de `Defensa`, `Ataque`, `Robo` o `Recursos`, o robar del mazo central.
3. **Fase de Noche (Asedio del Overlord):**
   - El Overlord ejecuta Condiciones de Ataque / Hordas contra objetivos específicos.
   - Resolución de dados (D6) contra murallas y defensas humanas.
4. **Fase de Mantenimiento:**
   - Consumo de 1 de Comida por facción viva. Penalización de 2 HP si no se dispone del alimento.
